# Investigating the Representation of Disability in Large Language Models

This repository contains the code and the datasets of the paper "<i>Investigating the Representation of Disability in Large Language Models</i>". This repository is still under construction.

## Annotated Datasets
The directory <i>DatasetsAnnotated/</i> contains the annotated posts by the three annotators (<i>1_ANN_csv.csv</i>, <i>2_ANN_csv.csv</i>, and <i>3_ANN_csv.csv</i>) respectively. The file <i>ANN.csv</i> merges these three files. The files <i>csv_NCR.csv</i>, <i>csv_depression.csv</i>, and <i>csv_vader.csv</i>, contain the annotations of emotion, depression level, and sentiment of the posts in <i>ANN.csv</i> respectively. 

## LLMs Generated datasets
The directory <i>DatasetsGenerated/</i> contains the posts generated by the three LLMs, namely gpt4o-mini, Mixtral-8B and Gemini-1.5Flash. The model used is indicated in the file name. The files ending with "generated.csv" contain the posts generated by the models when representing people with disabilities. The ones ending with "no-dis-360.csv" contain the posts generated when representing personas instead. As for the annotated datasets, the files ending with _NCR.csv_, _depression.csv_, or _VADER.csv_ contain the annotation of emotion, depression level, and sentiment of the posts, respectively.

## Datasets Corpora
The directory _DatasetsCorpora/_ contains the files used for extracting significantly different words with the z-score method.

## Code
The directory _Scripts/_ contains the scripts used to generate the posts with LLMs and annotate them with emotion, depression, and sentiment level.
The directory _Script_plot/_ contains the code use to generate the paper plots.
